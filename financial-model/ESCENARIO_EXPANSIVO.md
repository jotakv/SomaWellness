# ESCENARIO EXPANSIVO — Physical + Digital Upside

Última actualización: 2026-08-19

## Objetivo

Modelizar el potencial adicional una vez validado SOMA LAB y sin contaminar el caso bancario base.

## Negocio físico

- mayor ocupación;
- más talleres y eventos;
- programas de mayor ticket;
- mayor utilización de franjas valle;
- colaboraciones corporativas/hoteles/retiros cuando exista evidencia comercial.

## SOMA OS

Puede incorporar ingresos separados por:

- SaaS B2B;
- onboarding/implantación;
- servicios premium;
- suscripciones B2C futuras.

## Regla de prudencia

Los ingresos digitales sólo se incorporarán cuando exista una hipótesis comercial explícita y, preferentemente, datos de validación. No se utilizarán para justificar la capacidad inicial de pagar el inmueble.
