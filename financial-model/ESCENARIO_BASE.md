# ESCENARIO BASE

Última actualización: 2026-08-19

## Objetivo

Representar la hipótesis central de operación bancaria de SOMA LAB, sustentada sólo por el negocio físico.

## Regla estructural

**SOMA OS = 0 € de ingresos para servicio de deuda.**

## Drivers

- oferta física MVP acotada;
- ocupación progresiva;
- mix de memberships, bonos y drop-in;
- talleres/eventos como ingreso complementario;
- alquiler puntual de sala sólo si es compatible con licencia y operación;
- coste de profesionales ligado parcialmente a actividad;
- marketing decreciente tras fase de lanzamiento.

- EBITDA/resultado operativo;
- flujo de caja disponible para deuda;
- DSCR;
- LTV/LTC cuando exista tasación;
- break-even;
- caja mínima;
- sensibilidad a caída de ventas.
