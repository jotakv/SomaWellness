# SOMA Community

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

No es un clon de Instagram. Grafo alrededor de activities, groups, journeys, events, studios, creators y shared experiences. Funciones potenciales: groups, activity partners, challenges, event/creator communities, local community y journey cohorts.

Objetivo HIPÓTESIS: pasar de consumo a participación. Guardrails: consentimiento, privacidad, bloqueo/reporte, moderación, seguridad, accesibilidad y no explotar vulnerabilidad. Métricas: participación significativa, cohort retention y conexiones recíprocas; no tiempo de pantalla aislado.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
