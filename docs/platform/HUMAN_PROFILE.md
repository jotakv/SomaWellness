# SOMA Human Profile

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

Perfil no clínico, voluntario y editable. Dimensiones exploratorias **HIPÓTESIS**: movement, strength, mobility, energy, presence, connection, creativity, exploration, recovery y contemplative practice. Guarda objetivos, intereses, preferencias, disponibilidad e historial de SOMA con propósito y consentimiento.

No diagnostica, no registra enfermedades por diseño, no infiere psicología sensible y no produce scores pseudocientíficos. Cada dimensión debe tener procedencia (declarada/observada), uso explicado, visibilidad, rectificación, exportación y borrado.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
