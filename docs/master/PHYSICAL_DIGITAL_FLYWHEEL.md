# Flywheel físico–digital

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

## Modelo — HIPÓTESIS, no efecto observado

```text
SOMA LAB → Users + Creators → SOMA OS → Operational Data → SOMA AI
     ↑                                               ↓
External Studios ← Marketplace ← Content ← Creators ← Community
                                                     ↑
                Retention ← Better Experience ← Journeys + Recommendations
```

Cada centro externo podría aportar customers, bookings, experiences y creators sin ser propiedad de SOMA. El bucle solo existe si cada enlace demuestra causalidad, consentimiento, valor y adopción; sumar módulos no crea por sí mismo network effects. Métricas por enlace: activación, experiencias completadas, retención, creator supply, liquidez y adopción externa.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
