# Roadmap tecnológico

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

| Fase | Alcance | Gate de salida |
|---|---|---|
| 0 Discovery | ICP, problem, architecture, data | dolor y workflow observados |
| 1 SOMA LAB Core | CRM, booking, memberships, attendance | uso interno fiable |
| 2 AI | Receptionist, Retention, Recommendations | valor explicable y seguro |
| 3 Digital Consumer | Content, Human Profile, Journeys | repetición B2C |
| 4 Creator | Profile, Studio, Content | creators activos |
| 5 Community | groups, cohorts, challenges | participación, no solo consumo |
| 6 Marketplace | experiences, studios, booking | transacciones repetidas |
| 7 Retreats | consumer + organizer | dolor específico validado |
| 8 External SOMA OS | comercialización multi-tenant | pago y adopción externos |

El orden es **HIPÓTESIS** y deberá reordenarse si la evidencia cambia prioridad. Cada fase limita alcance y tiene kill criteria; no implica fechas ni compromiso de construcción.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
