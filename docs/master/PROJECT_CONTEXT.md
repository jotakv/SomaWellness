# Contexto del proyecto SomaWellness

## Propósito

Construir de forma incremental, versionada y auditable un plan de empresa para **SomaWellness**. En la iteración 00 solo queda establecida la infraestructura; no se concluye la viabilidad.

## Alcance estable

- El entregable es un plan de empresa acompañado por una web estática navegable.
- Cada iteración debe actualizar documentación, datos y validaciones relacionados con su alcance.
- Las afirmaciones relevantes deben indicar su estado y mantener trazabilidad.
- El repositorio debe permanecer funcional al cierre de cada iteración.

## Estados

| Estado | Uso |
|---|---|
| CONFIRMADO | Evidencia sólida y trazable. |
| DERIVADO | Resultado reproducible a partir de entradas identificadas. |
| ESTIMADO | Aproximación razonable aún no confirmada. |
| HIPÓTESIS | Supuesto explícito para analizar o modelizar. |
| PENDIENTE | Evidencia o decisión aún inexistente. |

## Límites actuales

El concepto detallado, alcance comercial y tesis se trabajarán en la iteración 01. El estudio profundo de mercado, el modelo financiero definitivo y la conclusión de viabilidad quedan expresamente fuera de este bootstrap.
