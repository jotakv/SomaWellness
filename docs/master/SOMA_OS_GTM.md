# Go-to-market de SOMA OS

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

## Secuencia condicionada

Customer Zero → 3 Design Partners → 5 External Pilots → First Paying Studio → 10 Paying Studios → Repeatable Sales Motion → 50 → 100 → 1.000. Los números son **gates HIPÓTESIS**, no clientes existentes.

Founder-led sales primero. Para cada design partner: ICP, problema probado, baseline, workflow manual, criterio de éxito, seguridad, duración y salida. No contar SOMA LAB como prueba de transferibilidad. Comercialización exige al menos un centro completamente independiente que use y pague recurrentemente por valor medible.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
