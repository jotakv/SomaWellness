# Moat tecnológico

> **Estado del documento:** blueprint interno. Salvo decisiones de diseño expresamente marcadas, las propuestas comerciales, problemas, efectos y adopción son **HIPÓTESIS**; los datos no disponibles son **PENDIENTE**. No acredita demanda, clientes, ventas ni viabilidad.

## CURRENT MOAT

**PENDIENTE / débil.** No existen datos acreditados de switching costs, red, liquidez, calidad algorítmica o marca defensible. La IA por sí sola no es un moat.

## POTENTIAL MOAT — HIPÓTESIS

Vertical workflows, behavioral dataset consentido, customer switching costs, creator network, physical distribution, marketplace liquidity, community graph, recommendation quality y brand. Cada candidato necesita métrica, contrafactual, plazo y evidencia externa. No usar datos entre tenants ni fines sin consentimiento para fabricar una ventaja.

## Puerta de validación

No avanzar por entusiasmo: evidencia del problema → solución manual → Customer Zero → uso → valor medible → piloto externo → disposición a pagar → adopción repetible. Registrar evidencia adversa y detener o reordenar si no se supera la puerta.
