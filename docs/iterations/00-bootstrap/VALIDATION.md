# Validación — Iteración 00

## Controles definidos

- `npm test`: valida sintaxis de todos los JSON, rutas HTML locales, existencia e igualdad del siguiente prompt y vocabulario de estados.
- `npm run check:content`: comprueba las restricciones del contenido público heredadas por el repositorio.

Los resultados finales se registran en el commit y en la descripción de la entrega; este documento describe el protocolo reproducible y evita afirmar resultados antes de ejecutar los comandos.
