# Guía de auditoría

1. Revisar `data/business-model.json` y aprobar cada hipótesis con fecha y owner.
2. Ejecutar `npm test`; comparar resultados con las tablas del navegador.
3. Verificar que `calculateRent(month)` aplica cada tramo de renta.
4. Sustituir entradas `PENDIENTE` por evidencia trazable, nunca por memoria.
5. Revisar escenario defensivo con presupuestos y aforo técnico reales.
6. Imprimir las páginas principales con la hoja de estilos de impresión.
7. Antes de invertir, completar los gates de `viabilidad.html`.
